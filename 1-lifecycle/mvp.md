## MVP — мінімально життєздатний продукт Gartic Phone

#### 1. Мета MVP<br>
Мета MVP — створити базову версію гри, яка дозволяє користувачам створювати ігрові кімнати, запрошувати друзів, малювати, вводити фрази та переглядати результати.

2. Розподіл функцій за MoSCoW<br>

| Пріоритет | Функціональність |
| --------- | ---------------- |
| Must Have | Створення ігрової кімнати |
| Must Have | Приєднання за посиланням |
| Must Have | Введення імені гравця |
| Must Have | Створення текстових фраз |
| Must Have | Малювання |
| Must Have | Передавання малюнків |
| Must Have | Перегляд результатів |
| Should Have | Таймер раунду |
| Should Have | Вибір ігрових режимів |
| Could Have | Додаткові інструменти малювання |
| Could Have | Налаштування зовнішнього вигляду |
| Won't Have | Мобільний застосунок |
| Won't Have | Платні підписки |


#### 3. Межі першого релізу<br>
Перший реліз повинен забезпечувати основний ігровий процес: створення кімнати, приєднання учасників, введення фраз, малювання та перегляд результатів.<br>

#### 4. Шлях користувача<br>
Користувач відкриває гру.<br>
Створює кімнату або приєднується до існуючої.<br>
Запрошує друзів.<br>
Починає гру.<br>
Вводить фрази та малює.<br>
Переглядає результати.<br>
