# Правила валідації вхідних даних

## 1. Загальні правила

Валідація потрібна для перевірки правильності даних, які вводить користувач. Вона допомагає уникати порожніх полів, неправильних форматів та некоректних значень.

|---|---|---|---|---|
| id | Додатне ціле число | 1 | -5 | ID має бути додатним числом |
| name | Від 2 до 100 символів | Іван | A | Ім'я має містити від 2 до 100 символів |

## 8. Загальні вимоги до валідації

- Обов'язкові поля не можуть бути порожніми.
- Числові ідентифікатори повинні бути додатними цілими числами.
- Електронна пошта повинна мати правильний формат.
- Довжина текстових полів повинна відповідати встановленим обмеженням.
- Дати повинні мати правильний формат.
- Зовнішні ключі повинні посилатися на наявні записи.
- Паролі не повинні зберігатися у відкритому вигляді.

## 9. Висновок

Визначено правила валідації для всіх шести сутностей продукту. Перевірка вхідних даних допомагає запобігати помилкам, забезпечує правильність інформації та підвищує надійність системи.
