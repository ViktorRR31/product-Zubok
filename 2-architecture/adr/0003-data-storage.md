# ADR 0003: Вибір способу зберігання даних

- **Статус:** Прийнято
- **Дата:** 12.11.2026

## 1. Контекст

Продукту необхідно зберігати інформацію, яку створюють або використовують користувачі. Потрібно обрати відповідний спосіб зберігання даних.

## 2. Варіанти

1. LocalStorage — зберігання даних безпосередньо у браузері.
2. SQLite — використання легкої реляційної бази даних.
3. PostgreSQL — використання повноцінної реляційної бази даних.

## 3. Рішення

Для першої версії продукту обрано LocalStorage. Він дозволяє зберігати невеликі обсяги інформації у браузері без налаштування окремого сервера бази даних.

## 4. Наслідки

- Просте збереження інформації.
- Не потрібне підключення до окремої бази даних.
- Дані зберігаються локально у браузері.
- Для масштабування продукту може знадобитися перехід на серверну базу даних.
