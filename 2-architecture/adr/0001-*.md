# ADR 0001: Вибір архітектурного стилю

- **Статус:** Прийнято
- **Дата:** 12.11.2026

## 1. Контекст

Для розробки продукту потрібно обрати архітектурний стиль, який забезпечить зрозумілу структуру програми, простоту розробки та можливість подальшого розширення.

## 2. Варіанти

1. Монолітна архітектура — усі основні компоненти працюють в одному застосунку.
2. Мікросервісна архітектура — система складається з окремих незалежних сервісів.
3. Клієнт-серверна архітектура — клієнт взаємодіє із сервером для отримання даних.

## 3. Рішення

Обрано клієнт-серверну архітектуру, оскільки вона дозволяє розділити інтерфейс користувача та серверну логіку.

## 4. Наслідки

- Зрозумілий розподіл компонентів системи.
- Можливість незалежно змінювати клієнтську та серверну частини.
- Потрібно налаштувати взаємодію між клієнтом і сервером.
