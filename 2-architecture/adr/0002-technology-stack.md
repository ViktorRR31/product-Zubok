# ADR 0002: Вибір технологій розробки

- **Статус:** Прийнято
- **Дата:** 12.11.2026

## 1. Контекст

Для створення продукту необхідно вибрати технології, які забезпечать розробку інтерфейсу, серверної частини та взаємодію між ними.

## 2. Варіанти

1. HTML, CSS та JavaScript — базові вебтехнології.
2. React та Node.js — інструменти для створення клієнтської та серверної частин.
3. Python та Django — технології для створення вебзастосунків.

## 3. Рішення

Обрано HTML, CSS та JavaScript як базові технології для розробки першої версії продукту.

## 4. Наслідки

- Простота початку розробки.
- Можливість створення інтерактивного інтерфейсу.
- Не потрібно використовувати складні додаткові інструменти.
- У майбутньому технологічний стек можна розширити.
